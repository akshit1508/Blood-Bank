# Packages Directory

This folder is designated for shared packages in the monorepo, such as:
- Shared TypeScript interfaces/types/DTO definitions (when applicable)
- Common utility libraries
- Shared configuration (eslint, tsconfig)

In Phase 0, all core architectural documentation and baseline applications (`apps/web` and `apps/api`) have been configured. Shared code will be extracted here cleanly as vertical slices evolve.
